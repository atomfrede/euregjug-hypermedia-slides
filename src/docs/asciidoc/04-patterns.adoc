== Form validation

[source,html,highlight="1,13|6,7,8,9|10"]
----
<form action="/" method="post" id="hx-form">
    <fieldset>
        <label>Firstname
        <input
                type="text"
                hx-trigger="keyup changed delay:250ms"
                hx-post="/"
                hx-include="closest form"
                hx-target="#hx-form"
                hx-swap="morph">
        </label>
    <fieldset>
    <button type="submit" value="Submit">Submit</button>
</form>
----

[.notes]
--
* normal form, can be used with usual submit w/o javascript
* trigger a `post` to `/` with *all* form parameters of the nearest form element
* targeting the form itselt
* using morph instead of default inner html replacement to keep selection and focus for example
--

== Form validation

[source,java,highlight="1,5,8"]
----
@PostMapping(headers="hx-request")
public String htmxPost(@Valid FormModel formModel, BindingResult bindingResult, Model model){
    model.addAttribute("formModel", formModel);
    model.addAttribute("validationResult", bindingResult);
    return "form";
}

@PostMapping
public String postIndex(@Valid FormModel formModel, BindingResult bindingResult, Model model){
    // usual form handling with redirect
}
----

[.notes]
--
* usual form submit with redirect
* `@HxRequest` from 3rd Party library, makes sure that endpoint is only called when htmx issued the request using a dedicated `Header` attribute (`hx-request`)
--

== Modal dialogs

* need to *create the content on demand*

* use *alpine to handle interaction* with the modal

== LLM Chat - First response

[source,html,highlight="1|2-5|7|8|9,10|11-12"]
----
<hx-partial hx-target="#chat-form" hx-swap="outerHTML">
<form id="chat-form">
    <input type="text" id="message-input"name="message" disabled placeholder="Thinking..." autocomplete="off">
    <button aria-busy="true" aria-label="Thinking..." disabled>Thinking...</button>
</form></hx-partial>

<hx-partial hx-target="#chat-container" hx-swap="beforeend transition:true">
    <div class="message user-message">${userMessage}</div>
    <div class="message bot-message" id="llm-answer-${streamIdentifier.toString()}"
        hx-sse:close="done" hx-sse:connect="/llm/stream/${streamIdentifier.toString()}">
            <span id="thinking-indicator" aria-busy="true">...</span>
            <div id="llm-answer-content-${streamIdentifier.toString()}"></div>
    </div></hx-partial>
----

[.notes]
--
* hx partial is new in 4, think oob, but more flexible
* replace the input with a disabled variant
* add the entered user message to the chat
* add the placehiolder for the bot message opening the sse connection
--
